# Nolan Asset Library — Shortlist v1

Purpose: maintain a curated, license-aware library of visual assets for Nolan Investment Office. This file is a shortlist and sourcing record, not a blanket approval to publish every asset.

## Selection rules
- Prefer assets with clear commercial-use terms.
- Avoid identifiable people, visible trademarks/logos, copyrighted artworks, and editorial-only imagery.
- Avoid generic finance imagery: handshakes, boardroom posing, stock-market screens, skyscraper clichés.
- Prefer architectural detail, materials, infrastructure, scientific equipment, product detail, light and shadow.
- Final website files should be locally optimized to WebP/AVIF where practical; do not hotlink production imagery.
- Keep photography secondary to the Nolan typography / SVG / modular visual system.

For the first media test, use only 5 visual assets:
1. A01 architectural image — Office
2. T01 data center — Technology
3. H01 diagnostics equipment — Healthcare
4. E01 electrical infrastructure — Energy & Infrastructure
5. C01 glass/material study — Selective Consumer

Plus one texture:
6. M01 concrete texture — low-opacity material overlay

Do not add Lottie yet. First verify that photography and material layers improve the site without weakening the current Nolan SVG / typographic identity.

## Implementation target
- Photography should occupy roughly 10–15% of the total site visual surface.
- No homepage full-screen photography in the first test.
- Prefer image panels, masked crops, partial reveals, and interaction-linked media.
- Images should not look like “portfolio holdings”; they illustrate areas of attention only.
- Add no invented portfolio/company associations.
