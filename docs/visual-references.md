# Visual References — Nolan Investment Office

The V1.7 visual refinement draws on general design and implementation ideas from the following MIT-licensed Astro projects. Nolan Investment Office retains its own information architecture, copy, branding, color system and page composition.

## Astro Nano
Repository: markhorn-dev/astro-nano
License: MIT

Ideas studied:
- lightweight fixed/translucent navigation
- restrained interaction timing
- minimal visual noise
- accessibility and responsive behavior

## Astro Sphere
Repository: markhorn-dev/astro-sphere
License: MIT

Ideas studied:
- minimalist content hierarchy
- lightweight page structure
- subtle interface movement
- performance-conscious presentation

## Astro Corporate Demo
Repository: chocolat5/astro-corporate-demo
License: MIT

Ideas studied:
- semantic design tokens
- spacing scale
- easing curves
- responsive corporate layout discipline

## Nolan implementation
The V1.7 implementation translates those general ideas into a private-investment-office editorial system:
- warm ivory / charcoal / muted olive palette
- editorial serif headlines with restrained sans-serif navigation
- hairline dividers and structured two-column text blocks
- subtle hover states rather than large animation effects
- a single-screen homepage preserved as a hard requirement
- no portfolio-logo wall, AUM claims, financial dashboard, or sales-style CTA
