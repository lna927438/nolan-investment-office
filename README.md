# Nolan Investment Office — V1.1

Minimal website for Nolan Investment Office, built as a quiet and understated private investment office presence.

Built with Astro.

## Current structure
- Hero
- Investment Focus
- Approach
- Office
- Contact
- Legal disclosures
- Custom 404 page

## Design direction
- Minimal private investment office style
- Warm ivory background
- Charcoal typography
- Muted olive accent
- Serif editorial headlines
- Generous whitespace
- Very limited motion
- Responsive mobile layout

## Technical details
- Astro static site
- No database
- No frontend framework dependency beyond Astro
- No analytics or tracking installed
- Basic SEO and social metadata
- Accessibility-friendly reduced-motion behavior
- GitHub Actions build verification

## Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Before public launch
The following should be finalized before deployment:

1. Official domain
2. Public office email address
3. Final legal entity name and legal disclosure review
4. Decision on whether to display a public LinkedIn profile
5. Optional selected portfolio or insights content
6. Hosting and deployment target
